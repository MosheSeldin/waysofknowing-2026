## 🚀 התקנה והרצה מקומית

1. שכפל את המאגר:
```bash
git clone https://github.com/YOUR-USERNAME/drachim-ladaat-events.git
```

2. פתח את `index.html` בדפדפן

## 🔧 התאמה אישית

### שינוי ה-URL של Google Apps Script

ערוך את `index.html` ומצא את השורה:
```javascript
const SCRIPT_URL = 'YOUR_SCRIPT_URL_HERE';
```

החלף ב-URL של ה-Apps Script שלך.

### הוספת אירוע חדש

העתק אחד מבלוקים הקיימים של `<div class="event">` והתאם את הפרטים.
