# 🔧 פתרון בעיות - Troubleshooting Guide

## 🚨 בעיות נפוצות ופתרונות

---

### ❌ בעיה 1: "לא קורה כלום כשאני לוחץ על כפתור ההרשמה"

**סימנים:**
- הכפתור לא פותח חלון הרשמה
- אין שום תגובה

**פתרונות:**
1. בדוק שהקוד JavaScript בתחתית הקובץ HTML לא נמחק
2. פתח את Console בדפדפן (F12 → Console) וחפש שגיאות
3. ודא שהקובץ הוא `.html` ולא `.txt`

---

### ❌ בעיה 2: "הטופס נשלח אבל לא מופיע בשיט"

**סימנים:**
- הודעת "תודה על ההרשמה" מופיעה
- אבל אין שום דבר בשיט

**פתרונות:**

✅ **וודא שה-URL נכון:**
```javascript
// בדוק בקובץ ה-HTML את השורה הזו:
const SCRIPT_URL = 'https://script.google.com/macros/s/...../exec';

// ודא ש:
// 1. יש https:// בהתחלה
// 2. יש /exec בסוף
// 3. אין רווחים או שורות חדשות
```

✅ **בדוק שפרסמת את הסקריפט:**
1. פתח את Apps Script Editor
2. לחץ Deploy → Manage deployments
3. ודא שיש deployment פעיל
4. אם אין - צור deployment חדש

✅ **בדוק את ההרשאות:**
1. ב-Apps Script, לחץ Deploy → Test deployments
2. ודא שזה מוגדר ל-"Anyone"
3. אם לא - שנה ל-"Anyone" ופרסם מחדש

---

### ❌ בעיה 3: "מקבל שגיאת CORS או 'blocked'"

**סימנים:**
```
Access to fetch at '...' from origin '...' has been blocked by CORS policy
```

**פתרון:**
זו לא באמת בעיה! הקוד משתמש ב-`mode: 'no-cors'` בדיוק בשביל לעקוף את זה.

**איך לוודא שזה עובד בכל זאת:**
1. צא מהטופס
2. פתח את ה-Google Sheet
3. אם ההרשמה שם - הכל תקין! ✅
4. השגיאה היא קוסמטית בלבד

---

### ❌ בעיה 4: "הסקריפט לא מוצא את השיט"

**סימנים:**
```
Cannot find function getActiveSheet in object
```

**פתרון:**
1. וודא שפתחת את Apps Script דרך השיט עצמו:
   - Sheet → Extensions → Apps Script
2. אל תיצור Apps Script standalone נפרד

---

### ❌ בעיה 5: "השדות בשיט לא מסודרים נכון"

**סימנים:**
- הנתונים מופיעים בעמודות לא נכונות
- הכותרות לא תואמות

**פתרון:**
1. מחק את שורת הכותרות הישנה (שורה 1)
2. מחק את כל השורות הישנות
3. שלח הרשמה חדשה
4. הכותרות יתווספו אוטומטית בפורמט הנכון

---

### ❌ בעיה 6: "שגיאה בשליחת הטופס"

**סימנים:**
- הודעת שגיאה אדומה מופיעה
- "אירעה שגיאה בשליחת הטופס"

**פתרונות:**

**א. בדוק חיבור לאינטרנט:**
- נסה לפתוח אתר אחר
- רענן את הדף ונסה שוב

**ב. נסה דפדפן אחר:**
- Chrome ✅
- Firefox ✅
- Safari ✅
- Edge ✅

**ג. בדוק שה-Script פועל:**
1. פתח Apps Script Editor
2. בחר בפונקציה `testSheet`
3. לחץ Run (▶️)
4. אם זה עובד - הסקריפט תקין

---

### ❌ בעיה 7: "טלפון לא נשמר נכון"

**סימנים:**
- מספר הטלפון מופיע כ-0 או מוזר

**פתרון:**
1. בשיט, סמן את עמודת הטלפון
2. לחץ Format → Number → Plain text
3. מהרגע הזה הטלפונים יישמרו נכון

---

### ❌ בעיה 8: "הטופס לא נסגר אחרי שליחה"

**סימנים:**
- הודעת הצלחה מופיעה
- אבל החלון לא נסגר אוטומטית

**פתרון:**
זה תקין! החלון נסגר אחרי 3 שניות.
אם תרצה לשנות את זה, חפש בקוד:
```javascript
setTimeout(() => {
    closeModal();
}, 3000);  // <-- שנה ל-1000 (1 שנייה) או 5000 (5 שניות)
```

## 🧪 איך לבדוק שהכל עובד?

### בדיקה מהירה (30 שניות):

1. **פתח את האתר**
2. **לחץ על כפתור "רוצה להגיע"**
   - ✅ חלון הרשמה נפתח?
3. **מלא פרטים ושלח**
   - ✅ כפתור השליחה הפך ל-"שולח..."?
   - ✅ הודעת "תודה על ההרשמה" מופיעה?
4. **פתח את ה-Google Sheet**
   - ✅ יש שורה חדשה עם ההרשמה?

אם על הכל יש ✅ - הכל עובד מצוין!

## 🐛 איך למצוא שגיאות?

### פתיחת Console בדפדפן:

**Windows/Linux:**
- Chrome/Edge: F12 או Ctrl+Shift+J
- Firefox: F12 או Ctrl+Shift+K

**Mac:**
- Chrome/Edge: Cmd+Option+J
- Firefox: Cmd+Option+K

### מה לחפש ב-Console:
```
✅ טוב: אין שום דבר או "Registration saved"
❌ רע: שגיאות אדומות או "Failed to fetch"
```

## 📞 עדיין לא עובד?

אם עדיין יש בעיה אחרי שניסית הכל:

1. **בדוק את המדריך המלא** - `SETUP-GUIDE.md`
2. **ודא שעקבת אחרי כל השלבים** בסדר הנכון
3. **נסה ליצור הכל מההתחלה** - לפעמים זה הכי מהיר

### רשימת צ'ק:
- [ ] יצרתי Google Sheet חדש
- [ ] פתחתי את Apps Script דרך השיט (Extensions → Apps Script)
- [ ] העתקתי את כל הקוד מ-`apps-script-code.gs`
- [ ] שמרתי את הפרויקט
- [ ] פרסמתי אותו (Deploy → New deployment)
- [ ] בחרתי "Anyone" ב-"Who has access"
- [ ] העתקתי את ה-Web App URL
- [ ] הדבקתי אותו בקובץ HTML במקום `YOUR_SCRIPT_URL_HERE`
- [ ] שמרתי את קובץ ה-HTML
- [ ] העליתי את האתר

## ✨ טיפים מתקדמים

### רוצה לקבל אימייל בכל הרשמה?

הוסף את זה לסוף הפונקציה `doPost`:

```javascript
// שלח לי אימייל
MailApp.sendEmail({
  to: "your-email@gmail.com",
  subject: "הרשמה חדשה: " + data.event,
  body: data.name + " נרשם לאירוע.\n\nטלפון: " + data.phone + "\nמשתתפים: " + data.participants
});
```

### רוצה לשמור גיבוי אוטומטי?

הוסף trigger:
1. Apps Script Editor → Triggers (שעון בצד)
2. Add Trigger
3. בחר פונקציה חדשה שמעתיקה את השיט
